Course Overview

Master Power System Analysis with ETAP

A comprehensive 6-session live online course covering essential power system studies using industry-standard ETAP software. Learn from industry best practices.

This intensive course provides hands-on training in power system analysis using ETAP, the industry-standard software for electrical power systems. You'll learn to perform load flow, short circuit, protection coordination, motor starting, and harmonic analysis studies.

Starting 15 August 2026, you'll gain practical skills directly applicable to real-world power system engineering. Each 2-3 hour session includes live demonstrations, guided practice, and Q&A. Participants receive practice materials.

Course Curriculum

8 Immersive Sessions

Each session combines theory, live ETAP demonstrations, and hands-on practice — fully aligned with industry practices.

Session 1: Power System Fundamentals & ETAP Introduction
Duration: 2-3 hrs Level: Beginner
Objectives
  • Understand power system structure and components (generation, transmission, distribution, loads)
  • Get familiar with ETAP interface, navigation, and workflow
  • Learn the difference between manual and auto-build modeling approaches
Topics
  • Power system overview: generation → transmission → distribution → load
  • Key components: transformers, generators, loads, circuit breakers, disconnect switches
  • ETAP software capabilities: Load Flow, Short Circuit, Motor Starting, Protection Coordination, Arc Flash, Harmonics, etc.
  • ETAP user interface: navigation, toolbars, workspace setup
  • Modeling philosophy: manual vs. auto-build, single-line diagram (SLD) creation best practices
  • ETAP project creation, saving, and management basics
Practice
  • Create a new ETAP project
  • Build a simple single-line diagram with source, transformer, and load
  • Navigate the ETAP workspace and explore toolbars
  • Practice manual and auto-build techniques
Assignment
  • Recreate a small industrial network SLD in ETAP (provided sketch)
  • Include at least: 2 buses, 1 transformer, 1 generator, 2 loads, 1 circuit breaker
  • Submit the ETAP project file for review
Session 2: Load Flow Analysis & Scenario Wizard
Duration: 2-3 hrs Level: Beginner
Objectives
  • Understand steady-state system behavior and load flow fundamentals
  • Learn to configure and run load flow studies in ETAP
  • Use ETAP's Scenario Wizard to manage different operating conditions
Topics
  • Load flow fundamentals: purpose, equations, bus types (Slack, PQ, PV)
  • Load modeling: constant impedance, constant current, constant power, composite loads
  • Load flow objectives: voltage profile analysis, % loading, losses calculation
  • ETAP Load Flow setup: study case creation, loading % adjustment, generation shifting
  • Scenario Wizard: creating configurations, study modes, cases; managing normal/emergency operations
  • Interpreting load flow results: voltage deviations, overloads, losses
Practice
  • Set up and run a load flow study on a sample system
  • Analyze voltage profiles and identify under/over-voltage buses
  • Check % loading of branches and identify overloaded elements
  • Calculate total system losses
Assignment
  • Create multiple scenarios (normal, peak load, generator outage) for the same system
  • Run load flow for each scenario and compare results
  • Document findings: worst-case voltage drops, overloads
Session 3: Short Circuit Analysis & Study Automation
Duration: 2-3 hrs Level: Beginner
Objectives
  • Calculate fault currents and evaluate equipment withstand capabilities
  • Automate studies using ETAP's Scenario & Study Wizard
  • Perform minimum and maximum short circuit calculations
Topics
  • Short circuit fundamentals: types of faults (3L, LL, LG, LLG), current symmetrical components
  • IEC and ANSI short circuit calculation methods
  • Key outputs: initial symmetrical current (Ik"), peak current (ip), breaking current (ib), etc.
  • ETAP Short Circuit module: study case setup, fault placement, calculation options
  • Equipment withstand validation: comparing calculated currents vs. equipment ratings
  • Scenario & Study Wizard: creating scenarios, grouping, executing study macros
  • Using shortcuts and favorites for repetitive studies
Practice
  • Perform minimum and maximum short circuit calculations
  • Check circuit breaker breaking capacity against fault currents
  • Verify bus bar short circuit withstand ratings
  • Experiment with different fault types and locations
Assignment
  • Perform a complete short circuit study (min/max) on the assigned system
  • Document: maximum fault current at each bus, equipment adequacy
  • Recommend any necessary equipment upgrades based on results
Session 4: Protection Fundamentals & Device Coordination
Duration: 2-3 hrs Level: Intermediate
Objectives
  • Understand protection philosophy and the role of protective devices
  • Learn protection requirements: speed, selectivity, sensitivity, reliability
  • Study different relay types and their applications
Topics
  • Power system faults: types, impacts, and clearing times
  • Protection basics: relay definition, function, and importance in power systems
  • Protection requirements: speed (fast clearing), selectivity (isolating fault), sensitivity (detecting faults)
  • Relay types: electromechanical, static, digital/numerical relays
  • Transformer protection: Buchholz relay, overcurrent, differential protection
  • Feeder protection: overcurrent, distance relays
  • Motor protection: overload, locked rotor, under-voltage
  • Introduction to ETAP's protective device coordination module
Practice
  • Explore ETAP's protective device coordination workspace
  • Review relay time-current curves (TCCs) in ETAP library
  • Practice basic coordination between upstream and downstream devices
Assignment
  • Select appropriate protective devices for a feeder circuit
  • Plot time-current curves and verify coordination
  • Ensure selective tripping for faults downstream
Session 5: Motor Starting Analysis
Duration: 2-3 hrs Level: Intermediate
Objectives
  • Understand motor starting characteristics and their impact on power systems
  • Analyze voltage dips and acceleration performance using ETAP
  • Evaluate motor starting methods and their effects on system stability
Topics
  • Motor starting fundamentals: starting current, torque-speed curves, acceleration time
  • Effects of motor starting on voltage dip and system stability
  • Starting methods: DOL, star-delta, auto-transformer, soft starter, VFD
  • ETAP Motor Starting module: study case setup, motor model parameters
  • Dynamic motor acceleration analysis: voltage and current profiles during start
  • Evaluation of starting performance and compliance with IEEE 399 / IEC standards
Practice
  • Set up and run a motor starting study on a sample system
  • Analyze voltage dip during motor start and compare with limits
  • Evaluate acceleration time and torque margins
  • Compare different starting methods and their impact
Assignment
  • Perform a motor starting study for a large induction motor
  • Assess voltage dip and recommend a suitable starting method
  • Document the analysis with ETAP reports
Session 6: Harmonics Analysis & Reporting
Duration: 2-3 hrs Level: Intermediate
Objectives
  • Understand harmonic sources and their effects on power quality
  • Perform harmonic analysis using ETAP's Harmonics module
  • Interpret harmonic distortion results and recommend mitigation measures
Topics
  • Harmonics fundamentals: sources, effects on equipment, and power quality issues
  • Harmonic distortion: individual harmonic distortion (IHD), total harmonic distortion (THD)
  • Harmonic standards: IEEE 519, IEC 61000 compliance
  • ETAP Harmonics module: modeling non-linear loads, harmonic sources
  • Frequency scan analysis and harmonic resonance
  • Filter design and mitigation techniques (passive and active filters)
Practice
  • Set up and run a harmonic analysis study in ETAP
  • Perform frequency scan to identify resonance conditions
  • Calculate THD and assess compliance with IEEE 519
  • Design a simple passive filter for harmonic mitigation
Assignment
  • Perform a complete harmonic analysis on an industrial system with VFDs
  • Identify harmonic resonance and propose mitigation
  • Generate a professional ETAP report with findings and recommendations
Session 7: Comprehensive Review, Q&A & Study Workshop
Duration: 2-3 hrs Level: Intermediate
Objectives
  • Reinforce the concepts covered throughout the course.
  • Resolve technical questions and common ETAP challenges.
  • Strengthen understanding through real-world engineering scenarios.
Topics
  • Comprehensive review of all previous study modules.
  • Power system modeling best practices.
  • Load Flow, Short Circuit, Protection Coordination, Motor Starting, and Harmonic Analysis recap.
  • Common ETAP modeling mistakes and troubleshooting techniques.
  • Engineering report interpretation and validation.
  • Open Q&A with real industrial case discussions.
Practice
  • Solve instructor-selected engineering scenarios.
  • Analyze and troubleshoot ETAP models.
  • Review previous assignments and improve study results.
  • Live troubleshooting session with participants.
Assignment
  • Revise previous assignments using instructor feedback.
  • Prepare your complete ETAP project for the final presentation.
Session 8: Final Project Presentation & Professional Workflow
Duration: 2-3 hrs Level: Advanced
Objectives
  • Demonstrate mastery of ETAP through a complete engineering project.
  • Learn how professional consultants present and validate their studies.
  • Receive personalized technical feedback and recommendations.
Topics
  • Complete industrial project walkthrough.
  • Engineering assumptions and study methodology.
  • Reviewing and validating study results.
  • Professional ETAP report generation.
  • Engineering recommendations and optimization techniques.
  • Career guidance and next learning roadmap.
Practice
  • Present your final ETAP project.
  • Discuss study assumptions and engineering decisions.
  • Review project outputs with the instructor.
  • Receive detailed technical feedback.
Final Project
  • Create a complete industrial ETAP model.
  • Perform Load Flow, Short Circuit, Motor Starting, Protection Coordination, and Harmonic studies.
  • Generate professional ETAP reports with engineering conclusions and recommendations.
  • Present and defend your engineering solution.
