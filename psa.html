Course overview

The studies utilities run every day, taught the way engineers actually use them.

PSS®E is one of the world's leading tools for power system planning, operation and stability work. Utilities, system operators and consultants rely on it to judge whether a network is performing, reliable and secure.

This course gives you the fundamentals and the practical skills to run the essential steady-state studies yourself, with an introduction to dynamic simulation and stability assessment. Every topic combines theory with hands-on work in the software.

Model the networkBuses, lines, transformers, generators
Solve the operating pointLoad flow and voltage profile
Stress-test itContingencies, voltage stability, faults
Automate with PythonRepeatable, scriptable studies
Expected outcomes

By the final lecture, you will work independently.

You will be able to run the core steady-state studies on your own, and you will understand the fundamentals of dynamic modelling and basic transient stability simulation.

Load flow analysis

Solve operating points, read bus voltages and line flows, and spot losses and limits.

Contingency analysis

Screen N-1 outages and identify the overloads and voltage violations they cause.

Voltage stability

Build P–V and Q–V curves and quantify how much margin the system has before collapse.

Short-circuit studies

Compute fault currents for protection settings and equipment ratings.

Python automation

Script PSS®E studies so you can run and repeat large case sets without manual clicks.

Dynamics & renewables

Understand rotor angle and frequency stability, plus the basics of renewable integration.

Curriculum

Eight lectures. One clear path.

Each week builds on the last: from building the model, to solving it, to stress-testing it, to automating and extending it.

01
Week 1 · 3hFoundations

Introduction to PSS®E & Power System Modeling

Navigate the software and build a power system model from data, the foundation for every study that follows.

  • Software environment
  • Network data structure
  • Model building
02
Week 2 · 3hModeling

Transmission Line Parameter Calculation with LineProp

Derive the resistance, reactance and susceptance of real conductor configurations and feed them into the model.

  • LineProp workflow
  • Conductor geometry
  • Parameter validation
03
Week 3 · 3hSteady state

Load Flow Analysis

Solve the network for a stable operating point and interpret voltages, flows and losses like a planning engineer.

  • Bus types
  • Convergence
  • Reading results
04
Week 4 · 3hSecurity

Contingency Analysis

Simulate outages one element at a time and find where the system breaks under N-1 conditions.

  • N-1 screening
  • Overload detection
  • Violation reports
05
Week 5 · 3hStability

Voltage Stability: P–V & Q–V Curves

Trace the nose curve of each load area and measure the margin between the operating point and voltage collapse.

  • P–V curves
  • Q–V curves
  • Reactive reserve
06
Week 6 · 3hFaults

Short-Circuit Analysis

Calculate fault levels across the network to support protection coordination and equipment selection.

  • Three-phase faults
  • Fault levels
  • Equipment ratings
07
Week 7 · 3hAutomation

PSS®E Automation with Python & Introduction to Dynamics

Turn repetitive studies into scripts, then take the first look at how a system behaves in time after a disturbance.

  • Python API basics
  • Batch studies
  • Dynamic analysis overview
08
Week 8 · 3hDynamics

Renewable Integration & Basic Dynamic Simulation

Introduce renewable integration and simulate rotor angle and frequency stability on a working case.

  • Renewable integration
  • Rotor angle stability
  • Frequency stability
