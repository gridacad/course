Course Overview

Master PSS®E Steady-State & IBR Grid Integration Studies

A focused 6-session professional program covering PSS®E steady-state analysis and Egyptian IBR grid-code compliance, using industry-standard PSS®E software.

This program delivers step-by-step guidance through PSS®E fundamentals, steady-state power flow analysis, short-circuit and contingency analysis, and PV/transfer limit and QV analysis with FACTS sizing — then moves into Egyptian IBR grid-code compliance, IBR modeling in PSS®E (PV/wind inverters, transformers, cables/TLs, grid equivalents), and a comprehensive IBR steady-state compliance assessment. Live PSS®E demonstrations and guided practice are included in every session.

Starting the week of 30 September 2026, you'll build industry-ready skills directly applicable to real-world power system and IBR grid integration studies. Each session includes live PSS®E demonstrations, hands-on practice, and Q&A. Participants receive practice materials.

Learning Outcomes

What You'll Be Able To Do

By the end of this course, participants will have mastered these core competencies.

Navigate PSS®E's toolbars, diagrams, data checking, and power flow solution engine with confidence.
Assess loading, voltage profiles, and limit-checking reports, and run short-circuit (SC) analysis in PSS®E.
Perform contingency analysis, PV/transfer limit studies, and QV analysis with FACTS sizing.
Explain Egyptian IBR grid-code requirements: LVRT/HVRT, reactive power & PQ capability, frequency response, and power quality/protection.

Run a comprehensive IBR grid-code compliance assessment: PQ capability, voltage profile, loading under max Q absorption/injection, and SC analysis.
Course Curriculum

6 Immersive Sessions

Each session combines theory, live PSS®E demonstrations, and hands-on practice.

01. PSS®E Overview
Introduction & getting started with PSS®E, toolbars and diagrams, data checking and management, and power flow solutions.
02. Steady-State Analysis I
Loading, voltage profile, and limit-checking reports, plus short-circuit (SC) analysis in PSS®E.
03. Steady-State Analysis II
Contingency analysis, PV and transfer limit analysis, and QV analysis with FACTS sizing.
04. Egyptian IBRs Grid Code Compliance Explanation
Fault ride-through (LVRT/HVRT) & operational envelope, reactive power/power factor obligations (PQ capability), active power & frequency response (ramp rate, droop), and power quality & protection requirements.
05. IBRs Modeling in PSS®E
PV/wind inverters modeling, 2W/3W transformers modeling, cables/TLs modeling, and grid equivalent modeling.
06. IBRs Grid Code Compliance | Comprehensive Steady-State Assessment
PQ capability assessment, voltage profile under various operating scenarios, loading under maximum reactive power absorption/injection, and SC analysis.
Optional. Advanced Topic — Time Series Power Flow
